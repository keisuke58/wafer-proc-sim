## 1. JST 早暁プログラム (最重要・今しか取れない)

**正式名称:** 大学発新産業創出基金事業「早暁プログラム」  
**URL:** https://www.jst.go.jp/program/startupkikin/sogyo-sp/index.html

### 概要
大学等の技術シーズを活用してスタートアップ設立を目指す「事業化人材(起業志望者)」を募集。
研究者とチームを組んで事業化検討 + 研究開発を行う。

### 支援内容
- ドアノック経費 (研究者への訪問・交渉費用)
- ステージ2研究開発費: **上限¥500万** (直接経費)
- 期間: ステージ1(5ヶ月) + ステージ2(7ヶ月) = 計12ヶ月

### 対象者要件
- 日本国内に居住し、プログラム期間中に国内で活動可能
- 事業化構想分野の専門知識 + ビジネス知識を保有
- ビジネスモデルが明確で実現性がある
- **現職を続けながら参加OK** ← Disco在籍中に申請できる
- 起業経験不要

### スケジュール (第3期)
| 項目 | 日程 |
|---|---|
| **公募期間** | **2026年4月10日〜7月13日正午** ← 今まさに募集中 |
| ステージ1 | 約5ヶ月 (シーズ探索・研究者とマッチング) |
| ステージ2 | 約7ヶ月 (事業化検討・研究開発) |
| 採択予定 | ステージ1: 20名 / ステージ2: 10チーム程度 |

### 審査基準
- ビジネスモデルの適切さ・実現性
- 技術分野の知識と課題解決能力
- 論理的な説明ができるか
- 書類選考 → 面接審査

### 西岡さんへの適用可能性
- wafer-proc-simは「大学での研究成果」として位置づけ可能
- 指導教員が研究者側として参加できる
- CITATION.cff・論文実績が審査で有利に働く
- **締切: 2026年7月13日 → 今すぐ動く**

### 申請窓口
大学の「産学連携本部」「TLO(技術移転機関)」に問い合わせる

## 2. JST START プログラム (旧来の制度)

**URL:** https://www.jst.go.jp/start/index.html

### 概要
大学等の「知」を社会で活用する日本型イノベーション・エコシステムの確立を目指す。
早暁プログラムの前身にあたる制度。現在は早暁プログラムが主流。

### プロジェクト種別
- **起業実証支援**: 事業化に向けた実証研究
- **ビジネスモデル検証支援**: 市場検証・顧客開発
- **SBIRフェーズ1支援**: 政府調達に向けた技術実証

## 3. NEDO ディープテック・スタートアップ支援事業

**URL:** https://www.nedo.go.jp/activities/introduction12.html

### 主要プログラム一覧

#### 3-1. ディープテック・スタートアップ支援事業 (DTSU)
- 対象: 研究開発型スタートアップ
- 分野: ロボティクス・AI・エレクトロニクス・IoT・素材など
- **半導体シミュレーションは対象分野に該当**
- 金額: 数千万〜1億円規模 (フェーズにより異なる)

#### 3-2. NEP 開拓コース (起業前向け)
- 対象: 起業前の個人またはチーム。ディープテック分野の技術シーズを持つ者
- 金額: **月額¥25万 × 12ヶ月 = 総額上限¥300万**
- 期間: 約12ヶ月
- 公募: 2026年1月〜2月 (次回は2027年初頭予定)
- URL: https://www.nedo.go.jp/koubo/CA2_100510.html

#### 3-3. 大企業等スタートアップ連携・調達加速化事業 (PoPフェーズ)
- 概要: 大企業との共創テーマで製品検証を行うフェーズ
- Disco・TEL等と組んで申請できる可能性あり

### NEDO申請のポイント
- 「研究開発」目的の費用にしか使えない (販売・営業費は不可)
- 採択後も毎年報告書の提出義務あり
- 共同研究機関 (大学等) があると採択率UP

## 4. 日本政策金融公庫「新規開業・スタートアップ支援資金」

**URL:** https://www.jfc.go.jp/n/finance/flow/tetsudukij_c.html  
※旧「新創業融資制度」は2024年3月廃止。現制度に引き継がれた。

### 概要
- 新たに事業を始める方、または事業開始後**おおむね7年以内**の方が対象
- 個人事業主・法人どちらでも利用可能

### 金額
- **融資限度額: ¥7,200万** (うち運転資金 ¥4,800万まで)
- 通常の申請では¥1,000〜3,000万が現実的

### 要件 (2026年時点)
- 自己資金要件: **撤廃** (以前は自己資金1/3以上が必要だったが廃止)
- 審査で重視される3点:
  1. 自己資金の有無・額
  2. 事業計画の実現性
  3. 返済原資の根拠

### 条件
- 原則**無担保・無保証人**で利用可
- 経営者保証免除特例制度あり (経営者の個人保証が不要)
- 金利: 1〜2%程度

### 申請の流れ
1. 支店 or 電話窓口で事前相談
2. 創業計画書の作成・提出
3. 審査 (約2〜4週間)
4. 融資実行

### 必要書類
- 創業計画書 (公式テンプレートあり)
- 運転免許証 / マイナンバーカード
- 事業に関する許認可書類 (該当する場合)

### 準備期間
**約1〜2ヶ月**。補助金の中で最も申請が簡単。

## 5. ものづくり補助金

**URL:** https://portal.monodukuri-hojo.jp/

### 概要
- 中小企業・小規模事業者の革新的な設備投資・試作品開発を支援
- 毎年複数回公募

### 金額
- 通常枠: 補助上限¥1,250万 (補助率1/2)
- デジタル枠: 補助上限¥2,500万
- グリーン枠: 補助上限¥4,000万

### 注意
- 設備投資・試作品開発が対象 (純粋なソフトウェア開発は対象外の場合あり)
- ただし「ソフトウェア + 検証用ハードウェア」の組み合わせなら申請可能
