研削/薄化（バックグラインド）の知能化

SiC/Siウェハの裏面研削・薄化（DGP/DFG、DBG/TAIKO）を対象に、 C++17でゼロから作った厚みマップ計測（TTV/WARP/BOW）・研削痕/サブサーフェス検査・ インフィードAPC制御・砥石摩耗予知・コスト/歩留りを統合。 以下はすべてツール（grind_demo）自身が出力した実測値です。

厚みマップ（TTV/WARP/BOW）

薄化後ウェハの厚み分布。最小二乗基準面で傾きを除去し非平坦性を評価。青＝薄、赤＝厚。

研削痕・サブサーフェスダメージ（SSD）

構造テンソルで研削痕の方向性を、高周波残差でSSDホットスポットを検出。明＝ダメージ大。

目標厚みのクローズドループ制御（インフィードAPC）

砥石が目減り（dulling）してもRun-to-Run EWMA制御でインフィードを補正し、最終厚みを目標100µmに維持。

オープンループ（固定インフィード） クローズドループ（APC） 目標 100µm

砥石摩耗の予知（研削力トレンド）

研削力の上昇を最小二乗でトレンド化し、ドレス限界（30N）までの残ウェハ数(RUL)を予測。

研削力 [N] ドレス限界 30N

コスト・歩留り統合

スループット・歩留り・消耗品・砥石寿命をダイあたりコストへ集約。
