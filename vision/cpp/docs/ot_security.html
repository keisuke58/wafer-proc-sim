Semiconductor Fab · IT/OT security architecture (Purdue model)

半導体Fab IT/OTセキュリティ構成図(Purdueモデル)

工場の情報系(IT)と装置・設備の制御系(OT)を、Purdueモデルの階層(L5〜L0)とセキュリティゾーンで分け、境界にファイアウォール/IPS/IDSを置く。装置はGEM/SECS/HSMSでデータを吸い上げ、上位のMES/EDA/SPC→Enterprise IT→クラウドへ流れる。装置データ収集基盤(時系列基盤)とセキュリティ(登録セキスペ)の交差点。公開ガイドライン概念(METIドラフト)の自作再現・学習用。
